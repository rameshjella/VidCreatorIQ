# VidCreatorIQ Web UI (React + Vite)

This frontend replaces Streamlit as the default local UI.

## Quick start

```bash
cd ui
npm install
npm run dev -- --host 127.0.0.1 --port 8501
```

Set API base URL via environment variable if needed:

```bash
set VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Build

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 8501
```
